## 项目结构

```
RenoucZion/
├── docs/                    # 文档目录
│   ├── AI/                  # AI 相关文档
│   ├── Nav/                 # 导航组件
│   ├── interview/           # 面试题文档
│   │   ├── 基础框架/        # React、Vue 等框架
│   │   ├── 计算机网络/      # 网络基础知识
│   │   ├── 语言相关/        # JavaScript 等语言
│   │   └── 面试题/          # 基础和进阶面试题
│   └── .vitepress/          # VitePress 配置
│       ├── config/          # 导航和侧边栏配置
│       ├── theme/           # 自定义主题
│       │   ├── components/  # 主题组件
│       │   └── styles/      # 主题样式
│       └── config.ts        # 主配置文件
├── package.json             # 项目依赖
└── .gitignore              # Git 忽略规则
```
