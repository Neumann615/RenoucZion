# 证券基础

---

## 一、证券的定义与特征

### 1.1 定义 📖

> **证券**是指各类记载并代表一定权利的法律凭证，它用以证明持有人有权依其所持凭证记载的内容而取得相应的权益。

### 1.2 特征 ⚡️

| 特征 | 说明 |
|------|------|
| **收益性** | 持有者可以获得一定的收益（股息、利息、资本利得等） |
| **风险性** | 收益具有不确定性，可能遭受本金损失 |
| **流动性** | 可以在证券市场上自由买卖、转让 |
| **期限性** | 有明确的到期日（股票除外，无期限） |
| **权责性** | 持有者享有相应的权利和承担相应的义务 |

## 二、证券的种类 🗂️

### 2.1 按性质分类

#### 2.1.1 股票 📈

- **定义**：股份公司发行的所有权凭证
- **特征**：不可返还性、收益性（股息、红利、资本利得）、风险性、流动性
- **种类**：普通股、优先股、A股、B股、H股、N股等

#### 2.1.2 债券 💵

- **定义**：政府、金融机构、企业等发行的债务凭证
- **特征**：返还性、收益性（利息）、安全性较高、流动性
- **种类**：政府债券（国债、地方政府债）、金融债券、企业债券（公司债、企业债）、可转债

#### 2.1.3 基金 📦

- **定义**：将投资者的资金汇集起来，由专业基金管理人管理和运作
- **特征**：集合投资、专业管理、分散风险、流动性
- **种类**：公募基金、私募基金、开放式基金、封闭式基金

#### 2.1.4 衍生品 🎲

- **定义**：以基础资产为标的的金融合约
- **特征**：杠杆性、风险性高、投机性强
- **种类**：期货、期权、远期、互换

### 2.2 证券种类对比表

| 证券类型 | 发行主体 | 收益方式 | 风险等级 | 流动性 |
|----------|----------|----------|----------|--------|
| **股票** | 股份公司 | 股息、红利、资本利得 | ⭐⭐⭐⭐⭐ | 高 |
| **债券** | 政府/金融机构/企业 | 利息、本金返还 | ⭐⭐ | 较高 |
| **基金** | 基金公司 | 净值增长、分红 | ⭐⭐⭐ | 高 |
| **衍生品** | 交易所/金融机构 | 价差收益 | ⭐⭐⭐⭐⭐ | 较高 |

## 三、证券市场 🏛️

### 3.1 定义

> **证券市场**是指证券发行和交易的场所，是资本市场的重要组成部分，实现资金从投资者向融资者的转移。

### 3.2 分类

#### 3.2.1 按功能分类

- **发行市场（一级市场）**：证券首次发行的场所
- **交易市场（二级市场）**：已发行证券交易的场所

#### 3.2.2 按交易对象分类

- 股票市场、债券市场、基金市场、衍生品市场

#### 3.2.3 按组织形式分类

- 场内市场（交易所市场）、场外市场（OTC市场）

### 3.3 证券市场参与者

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   发行人    │───▶│   中介机构  │───▶│   投资者    │
│ 政府/金融/企业│    │券商/律所/会所│    │个人/机构    │
└─────────────┘    └─────────────┘    └─────────────┘
        │                  │                  │
        ▼                  ▼                  ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   监管机构  │◀───│   交易所    │◀───│   中登公司  │
│   证监会    │    │   上交所/深交所│   │   登记结算  │
└─────────────┘    └─────────────┘    └─────────────┘
```

| 参与者类型 | 主要成员 | 职责 |
|------------|----------|------|
| **发行人** | 政府、金融机构、企业 | 发行证券募集资金 |
| **投资者** | 个人投资者、机构投资者 | 购买证券获取收益 |
| **中介机构** | 证券公司、会计师事务所、律师事务所 | 提供承销、审计、法律等服务 |
| **监管机构** | 证监会、交易所、证券业协会 | 监督管理市场运行 |

## 四、证券公司 🏢

### 4.1 定义

> **证券公司**是指依照《公司法》和《证券法》设立的经营证券业务的有限责任公司或股份有限公司。

### 4.2 主要业务

| 业务类型 | 说明 | 收入来源 |
|----------|------|----------|
| **证券经纪业务** | 为客户提供证券交易服务 | 佣金收入 |
| **证券承销业务** | 帮助发行人发行证券（代销/包销） | 承销费 |
| **证券自营业务** | 以自有资金买卖证券 | 投资收益 |
| **证券投资咨询业务** | 为客户提供投资建议 | 咨询费 |
| **财务顾问业务** | 为企业提供并购重组等服务 | 顾问费 |
| **资产管理业务** | 管理客户资产 | 管理费、业绩报酬 |

### 4.3 证券公司组织架构

```
证券公司
├── 投资银行部（承销业务）
├── 经纪业务部（交易服务）
├── 资产管理部（资管业务）
├── 研究部（研究报告）
├── 风险管理部（风险控制）
└── 合规部（合规管理）
```

## 五、证券发行制度 📝

### 5.1 发行制度对比

| 制度类型 | 审核方式 | 核心特点 | 适用市场 |
|----------|----------|----------|----------|
| **注册制** | 形式审核，强调信息披露 | 市场化定价，监管不判断投资价值 | 科创板、创业板 |
| **核准制** | 实质审核 | 监管判断投资价值，准入门槛较高 | 主板 |
| **审批制** | 政府审批 | 行政色彩浓厚，计划经济特征 | 已基本取消 |

> **注册制**的核心是"信息披露"，让投资者自主判断投资价值；**核准制**的核心是"实质审核"，由监管机构判断是否符合发行条件。

## 六、证券交易制度 ⚙️

### 6.1 交易方式

- **集中竞价交易**：通过交易所系统撮合成交
- **大宗交易**：大额交易，单独撮合
- **协议转让**：双方协商定价转让

### 6.2 交易规则

```
价格优先：较高买入申报优先于较低买入申报
时间优先：同价位申报，先申报者优先成交
涨跌幅限制：主板±10%，科创板/创业板±20%
T+1交易：当日买入，次日卖出
```

### 6.3 清算交收

- 净额清算、银证转账、交收风险控制

## 七、证券投资分析 🔍

### 7.1 分析方法对比

| 分析方法 | 核心内容 | 适用场景 |
|----------|----------|----------|
| **基本面分析** | 宏观经济、行业分析、公司分析 | 长期投资 |

## 八、证券市场监管 🛡️

### 8.1 监管机构

- **中国证券监督管理委员会（证监会）**：行政监管
- **证券交易所**：自律监管
- **证券业协会**：行业自律

### 8.2 监管内容

| 监管领域 | 主要内容 |
|----------|----------|
| **发行监管** | 审核发行申请，监督信息披露 |
| **交易监管** | 监控交易行为，维护市场秩序 |
| **信息披露监管** | 确保信息真实、准确、完整 |
| **投资者保护** | 教育投资者，维护合法权益 |

## 九、证券市场发展趋势 🚀

### 9.1 市场化改革
- 注册制全面推行、市场化定价机制、放宽市场准入

### 9.2 国际化发展
- 沪港通、深港通、债券通、外资准入放宽

### 9.3 科技创新
- 金融科技应用、数字化转型、智能投顾

### 9.4 投资者保护
- 完善投资者教育、强化信息披露、打击违法违规行为

---

## 十、总结 📋

> **证券市场**是资本市场的重要组成部分，通过证券发行和交易，实现资金从投资者向融资者的转移。**证券公司**作为中介机构，在证券市场中发挥着重要作用。随着市场化改革和国际化发展，证券市场将更加成熟和完善。
