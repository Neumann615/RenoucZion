# 项目发行

---

## 一、发行概述 📢

### 1.1 定义

> **项目发行**是指证券经监管机构核准或注册后，通过承销商向投资者销售证券的过程，是证券从发行人到投资者的关键环节。

### 1.2 发行方式分类

#### 1.2.1 按发行对象分类

| 发行方式 | 说明 | 特点 |
|----------|------|------|
| **公募发行** | 向不特定公众投资者发行 | 受众广、流动性强、需公开信息披露 |
| **私募发行** | 向特定投资者发行 | 受众有限、灵活性高、信息披露要求较低 |

#### 1.2.2 按承销方式分类

| 承销方式 | 说明 | 风险承担 |
|----------|------|----------|
| **代销** | 承销商代理销售 | 不承担发行失败风险 |
| **包销** | 承销商全额认购 | 承担发行失败风险 |
| - 全额包销 | 承销商全部认购 | 风险最高 |
| - 余额包销 | 承销商认购剩余部分 | 风险适中 |

#### 1.2.3 按发行渠道分类

| 渠道 | 说明 |
|------|------|
| **网上发行** | 通过证券交易所交易系统发行 |
| **网下发行** | 通过承销商向机构投资者发行 |
| **战略配售** | 向战略投资者定向配售 |

### 1.3 发行流程概览 ⚡️

```
发行准备 → 路演推介 → 询价定价 → 申购配售 → 资金募集 → 证券登记 → 上市交易
   │          │          │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼          ▼          ▼
方案制定   投资者沟通   确定价格   分配股份   收取资金   登记确权   挂牌交易
```

## 二、发行准备 📋

### 2.1 发行方案制定

| 要素 | 说明 |
|------|------|
| **发行规模** | 根据资金需求和市场情况确定 |
| **发行价格区间** | 初步确定价格范围 |
| **发行方式选择** | 网上/网下/战略配售组合 |
| **承销团组建** | 确定主承销商和联席承销商 |
| **时间安排** | 制定详细的发行时间表 |

### 2.2 发行文件准备 📁

- ✅ 招股说明书/募集说明书（定稿）
- ✅ 发行公告
- ✅ 投资风险特别公告
- ✅ 承销协议
- ✅ 承销团协议

### 2.3 市场准备

- 确定发行时机、分析市场环境、制定销售策略

### 2.4 技术准备

- 发行系统测试、网下申购系统准备、资金结算系统准备

## 三、路演推介 🎤

### 3.1 定义

> **路演**是指承销商组织发行人向投资者进行推介，介绍公司情况和投资价值，是连接发行人和投资者的重要桥梁。

### 3.2 路演目的

| 目的 | 说明 |
|------|------|
| **提高知名度** | 提升发行人市场知名度 |
| **展示价值** | 展示公司投资价值和亮点 |
| **收集反馈** | 收集投资者意见和反馈 |
| **定价参考** | 为最终定价提供参考依据 |

### 3.3 路演形式对比

| 路演形式 | 特点 | 适用场景 |
|----------|------|----------|
| **现场路演** | 在北京、上海、深圳等主要城市举办推介会，管理层现场介绍 | 大型IPO项目 |
| **网上路演** | 通过互联网平台在线推介，投资者在线提问 | 所有项目 |
| **一对一推介** | 针对大型机构投资者单独推介 | 机构投资者密集的项目 |

### 3.4 路演内容

```
┌─────────────────────────────────────────────────┐
│                  路演内容框架                    │
├─────────────────────────────────────────────────┤
│  1. 公司概况（发展历程、核心优势）              │
│  2. 业务和技术（主营业务、技术实力）            │
│  3. 财务状况（财务数据、盈利能力）              │
│  4. 发展战略（未来规划、发展目标）              │
│  5. 募集资金用途（资金投向、项目计划）          │
│  6. 风险因素（风险提示、应对措施）              │
└─────────────────────────────────────────────────┘
```

### 3.5 路演注意事项 ⚠️

- 信息披露准确、避免承诺性表述
- 保持客观中立、遵守监管规定

## 四、询价定价 💰

### 4.1 询价定义

> **询价**是指承销商向机构投资者询问对发行价格的意见，确定发行价格区间，是市场化定价的核心环节。

### 4.2 询价对象

| 机构类型 | 说明 |
|----------|------|
| **证券公司** | 自营投资部门 |
| **基金公司** | 公募基金、私募基金 |
| **保险公司** | 保险资金投资部门 |
| **信托公司** | 信托计划投资部门 |
| **财务公司** | 企业集团财务公司 |

### 4.3 询价流程

```
1. 初步询价
   ├── 向询价对象发送询价邀请
   ├── 询价对象提交报价
   └── 确定发行价格区间

2. 累计投标询价
   ├── 在价格区间内进行累计投标
   └── 确定最终发行价格
```

### 4.4 定价原则

| 原则 | 说明 |
|------|------|
| **市场化定价** | 由市场供需决定价格 |
| **兼顾利益** | 兼顾发行人利益和投资者利益 |
| **参考估值** | 参考市场同类公司估值 |
| **考虑供求** | 考虑市场供求关系 |

### 4.5 定价方法

| 方法 | 说明 |
|------|------|
| **市盈率法** | 根据市盈率确定价格 |
| **市净率法** | 根据市净率确定价格 |
| **现金流折现法** | 根据未来现金流折现确定价格 |
| **可比公司法** | 参考同类公司定价 |

### 4.6 超额配售选择权 🎯

> **超额配售选择权（绿鞋机制）**：承销商在发行后30日内，有权超额配售不超过发行数量15%的股票，目的是稳定股价，行使条件是股价低于发行价。

## 五、申购配售 📥

### 5.1 申购方式对比

| 申购方式 | 说明 | 投资者类型 |
|----------|------|----------|
| **网上申购** | 通过证券交易所交易系统申购 | 个人投资者为主 |
| **网下申购** | 通过承销商向机构投资者申购 | 机构投资者 |
| **战略配售** | 向战略投资者定向配售 | 战略投资者 |

### 5.2 申购流程

```
1. 申购公告 → 发布申购公告（时间、价格、数量）
2. 投资者申购 → 通过交易系统或承销商提交申购
3. 申购资金冻结 → 冻结申购资金
4. 配号抽签 → 配号并抽签确定中签号码
5. 中签结果公布 → 公布中签结果
6. 资金解冻 → 未中签资金解冻
```

### 5.3 配售原则

| 原则 | 说明 |
|------|------|
| **公平公正** | 所有投资者机会均等 |
| **优先中小投资者** | 优先满足中小投资者需求 |
| **机构配售比例限制** | 机构投资者配售比例有限制 |
| **战略投资者锁定期** | 战略投资者有较长锁定期 |

## 六、资金募集 💰

### 6.1 资金缴纳方式

| 申购方式 | 缴纳方式 |
|----------|----------|
| **网上申购** | 通过证券交易系统缴纳 |
| **网下申购** | 通过银行转账缴纳 |
| **战略配售** | 通过银行转账缴纳 |

### 6.2 资金管理

| 环节 | 说明 |
|------|------|
| **资金冻结** | 申购资金冻结期间不计利息 |
| **资金清算** | 确定中签金额，清算未中签资金 |
| **资金监管** | 募集资金专户存储，监管机构监督 |

## 七、证券登记 📝

### 7.1 登记机构

> **中国证券登记结算有限责任公司（中登公司）**：负责证券登记、存管、结算的法定机构。

### 7.2 登记流程

```
1. 证券发行登记 → 发行人提交发行信息
2. 投资者证券登记 → 开立证券账户，登记持有情况
3. 证券存管 → 证券存管在投资者账户中
```

### 7.3 登记内容

| 内容 | 说明 |
|------|------|
| **证券数量** | 持有证券的数量 |
| **持有人信息** | 投资者身份信息 |
| **持有时间** | 持有起始时间 |
| **限售信息** | 是否有限售限制 |

## 八、上市交易 📈

### 8.1 上市条件

| 条件 | 说明 |
|------|------|
| **符合上市规则** | 符合交易所上市规则 |
| **发行数量和市值** | 满足交易所要求 |
| **公司治理** | 公司治理结构完善 |
| **信息披露** | 信息披露规范 |

### 8.2 上市流程

```
1. 上市申请 → 向交易所提交上市申请
2. 上市审核 → 交易所审核申请
3. 上市安排 → 确定上市日期
4. 上市公告 → 发布上市公告书
5. 挂牌交易 → 证券在交易所挂牌交易
```

### 8.3 上市首日交易

| 事项 | 说明 |
|------|------|
| **涨跌幅限制** | 部分市场无涨跌幅限制 |
| **开盘价确定** | 集合竞价确定开盘价 |
| **交易方式** | 连续竞价交易 |

### 8.4 上市后持续义务

| 义务 | 说明 |
|------|------|
| **信息披露义务** | 定期报告、临时报告 |
| **持续督导义务** | 保荐机构持续督导 |

## 九、发行费用 💸

### 9.1 费用构成

| 费用类型 | 说明 | 收费标准 |
|----------|------|----------|
| **承销费用** | 承销商收取 | 发行金额的1%-5% |

| **会计师费** | 会计师事务所收取 | 固定或按小时 |

### 9.2 费用支付

> 发行成功后支付，从募集资金中扣除。

## 十、发行风险控制 🛡️

### 10.1 风险类型

| 风险类型 | 具体表现 |
|----------|----------|
| **发行失败风险** | 申购不足、定价过高、市场环境恶化 |
| **承销风险** | 包销导致库存积压、价格下跌损失 |
| **市场风险** | 上市后股价下跌、投资者投诉 |

### 10.2 风险控制措施

- ✅ 合理定价
- ✅ 充分路演
- ✅ 组建承销团
- ✅ 运用超额配售选择权

## 十一、发行案例分析 📚

### 11.1 案例一：某科技公司IPO

**发行概况** 📊

| 项目 | 内容 |
|------|------|
| **发行规模** | 10亿元 |
| **发行价格** | 20元/股 |
| **发行方式** | 网上+网下 |
| **中签率** | 0.05% |

**发行过程** 📝

1. **路演推介**：在北京、上海、深圳举办现场路演，同时进行网上路演
2. **询价定价**：初步询价确定价格区间18-22元，累计投标询价确定发行价20元
3. **申购配售**：网上申购倍数500倍，网下申购倍数30倍
4. **资金募集**：冻结资金1000亿元
5. **上市交易**：上市首日涨幅40%

**案例启示** 💡

> - **充分的路演推介**有助于提高发行成功率
> - **合理定价**是发行成功的关键

### 11.2 案例二：某公司债券发行

**发行概况** 📊

| 项目 | 内容 |
|------|------|
| **发行规模** | 50亿元 |
| **发行利率** | 3.5% |
| **发行期限** | 5年 |
| **信用评级** | AAA |

**发行过程** 📝

1. **信用评级**：聘请评级机构进行信用评级，获得AAA评级
2. **路演推介**：向机构投资者进行一对一推介
3. **询价定价**：确定发行利率3.5%
4. **申购配售**：机构投资者申购踊跃，超额认购3倍
5. **上市交易**：成功上市交易

**案例启示** 💡

> - **信用评级**对债券发行至关重要
> - **机构投资者**是债券发行的主要参与者

## 十二、总结 📋

> **项目发行**是证券从发行人到投资者的关键环节，涉及路演推介、询价定价、申购配售等多个步骤。承销商需要根据市场情况和发行人需求，制定合理的发行方案，确保发行成功。同时，要注意控制发行风险，保护投资者利益。
