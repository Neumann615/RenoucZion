# 项目承做

---

## 一、承做概述 📋

### 1.1 定义

> **项目承做**是指证券公司作为主承销商或联席主承销商，协助发行人完成证券发行的全过程，包括尽职调查、材料制作、申报审核、发行上市等环节。

### 1.2 承做角色分工

| 角色 | 职责 |
|------|------|
| **主承销商** | 负责项目的整体统筹和协调，对项目质量负总责 |
| **联席主承销商** | 协助主承销商开展工作，分担承销任务 |
| **承销团** | 由多家证券公司组成，共同承担承销任务和风险 |

### 1.3 承做流程概览 ⚡️

```
项目立项 → 尽职调查 → 材料制作 → 内核审核 → 监管申报 → 反馈回复 → 发行上市
   │          │          │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼          ▼          ▼
 评估筛选   全面调查   编制申报   内部把关   提交申请   解答疑问   成功发行
```

## 二、项目立项 🚩

### 2.1 立项条件

| 条件类别 | 具体要求 |
|----------|----------|
| **政策合规** | 发行人符合国家产业政策 |
| **发展前景** | 发行人具有良好的发展前景 |
| **投资价值** | 项目具有可行性和投资价值 |
| **承做能力** | 证券公司具有承做能力和资源 |

### 2.2 立项流程

```
1. 项目来源 → 主动营销 / 客户推荐 / 招标获取
2. 初步评估 → 发行人基本情况 / 行业发展趋势 / 项目可行性
3. 立项申请 → 提交立项申请报告（项目背景、可行性、风险）
4. 立项审批 → 投资银行部审核 → 风险管理部审核 → 内核委员会审批
```

### 2.3 立项材料清单 📁

- ✅ 立项申请书
- ✅ 发行人基本情况介绍
- ✅ 行业分析报告
- ✅ 项目可行性研究报告
- ✅ 风险评估报告

## 三、尽职调查 🔍

### 3.1 定义

> **尽职调查**是指承销商对发行人进行全面、深入的调查，了解发行人的财务状况、经营情况、法律合规等方面的真实情况，是项目承做的基石。

### 3.2 尽职调查目的

| 目的 | 说明 |
|------|------|
| **信息验证** | 确保发行人信息披露真实、准确、完整 |
| **风险识别** | 发现潜在风险和问题 |
| **定价依据** | 为定价和销售提供依据 |

### 3.3 尽职调查内容分类

#### 3.3.1 业务尽职调查 📊

- 发行人主营业务、行业地位和竞争优势
- 商业模式和盈利模式、产品和服务
- 市场份额和客户群体、技术研发和创新能力

#### 3.3.2 财务尽职调查 💰

- 财务报表审计、资产负债情况
- 盈利能力分析、现金流状况
- 财务风险评估、关联方交易

#### 3.3.3 法律尽职调查 ⚖️

- 公司治理结构、股权结构
- 合规经营情况、重大法律诉讼
- 知识产权、劳动用工

#### 3.3.4 其他尽职调查 🌱

- 环境保护、社会责任、税务合规

### 3.4 尽职调查方法

| 方法 | 说明 |
|------|------|
| **查阅资料** | 审阅公司文件、合同、财务报表等 |
| **访谈管理层** | 与公司高管面对面交流 |
| **实地考察** | 走访公司办公场所、生产基地 |
| **函证核实** | 向银行、客户、供应商发函确认 |
| **数据分析** | 对财务数据进行深度分析 |

### 3.5 尽职调查报告结构

```
┌─────────────────────────────────────────┐
│         尽职调查报告                    │
├─────────────────────────────────────────┤
│  1. 调查背景和目的                      │
│  2. 调查范围和方法                      │
│  3. 调查发现和问题                      │
│  4. 风险评估和建议                      │
│  5. 结论和意见                          │
└─────────────────────────────────────────┘
```

## 四、材料制作 📝

### 4.1 材料种类

#### 4.1.1 招股说明书（IPO）📄

- 发行人基本情况、业务和技术
- 财务会计信息、管理层讨论与分析
- 募集资金运用、风险因素

#### 4.1.2 债券募集说明书 💵

- 发行人基本情况、财务状况
- 募集资金用途、偿债计划
- 风险提示

#### 4.1.3 其他材料 📋

- 保荐工作报告、法律意见书
- 审计报告、资产评估报告
- 信用评级报告

### 4.2 材料制作要求

> **材料制作必须遵循"真实、准确、完整"的原则，符合监管要求，格式规范统一，语言通俗易懂。**

| 要求 | 说明 |
|------|------|
| **真实** | 所有信息必须真实可靠，不得虚假陈述 |
| **准确** | 数据和表述必须精确无误 |
| **完整** | 信息披露必须全面，不得遗漏 |
| **规范** | 格式符合监管机构要求 |

## 五、内核审核 🔒

### 5.1 内核定义

> **内核**是指证券公司内部对发行申请材料进行的审核，确保材料符合监管要求和公司内部标准，是风险控制的关键环节。

### 5.2 内核流程

```
1. 材料提交 → 承销商将申请材料提交内核委员会
2. 内核审核 → 内核委员对材料进行审核
3. 问题反馈 → 内核委员提出审核意见
4. 材料修改 → 承销商根据审核意见修改材料
5. 内核通过 → 内核委员会出具内核意见
```

### 5.3 内核重点关注事项 ⚠️

| 关注领域 | 重点内容 |
|----------|----------|
| **信息披露质量** | 披露是否充分、准确 |
| **财务真实性** | 财务数据是否真实可靠 |
| **法律合规性** | 是否存在法律风险 |
| **风险揭示充分性** | 风险是否全面揭示 |
| **募集资金合理性** | 资金用途是否合理 |

## 六、监管申报 📤

### 6.1 申报材料清单

- ✅ 发行申请报告
- ✅ 招股说明书/募集说明书
- ✅ 保荐工作报告
- ✅ 法律意见书
- ✅ 审计报告
- ✅ 其他相关材料

### 6.2 申报流程

```
1. 材料准备 → 承销商准备完整的申报材料
2. 网上申报 → 通过证监会网站提交电子材料
3. 材料受理 → 证监会受理申报材料
4. 审核排队 → 进入审核队列
```

### 6.3 审核阶段

| 阶段 | 说明 |
|------|------|
| **预审阶段** | 证监会对申报材料进行初步审查 |
| **反馈阶段** | 证监会提出反馈意见，发行人回复 |
| **初审阶段** | 证监会进行全面审核 |
| **发审会阶段** | 发行审核委员会审议表决 |

## 七、反馈回复 💬

### 7.1 反馈类型

| 反馈类型 | 常见问题 |
|----------|----------|
| **规范性问题** | 格式、表述等不符合要求 |
| **信息披露问题** | 信息披露不充分、不准确 |
| **财务问题** | 财务数据、会计处理等问题 |
| **法律问题** | 法律合规、股权结构等问题 |
| **业务问题** | 商业模式、行业地位等问题 |

### 7.2 反馈回复流程

```
收到反馈 → 问题分析 → 补充材料 → 回复撰写 → 内部审核 → 提交回复
   │          │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼          ▼
 证监会    制定策略   收集数据   撰写报告   质量把关   正式提交
```

### 7.3 反馈回复要求

> **反馈回复必须针对性强、数据详实、逻辑清晰、合规合理，直接回应监管关注的问题。**

| 角色 | 职责 |

## 九、承做风险控制 🛡️

### 9.1 风险类型

| 风险类型 | 具体表现 |
|----------|----------|
| **合规风险** | 发行程序不合规、虚假陈述、内幕交易 |
| **市场风险** | 市场环境变化、发行失败风险、承销风险 |
| **操作风险** | 材料制作错误、审核遗漏问题、沟通协调失误 |

### 9.2 风险控制措施

- ✅ 建立风险评估机制
- ✅ 加强内部审核
- ✅ 规范操作流程
- ✅ 加强人员培训

## 十、承做案例分析 📚

### 10.1 案例一：某公司IPO项目

**项目背景** 🌐

某科技公司计划在**科创板**上市，发行股票融资。

**承做过程** 📝

1. **项目立项**：评估公司技术实力和市场前景，确定立项
2. **尽职调查**：对公司业务、财务、法律进行全面调查
3. **材料制作**：编制招股说明书及其他申请材料
4. **内核审核**：内部审核通过
5. **监管申报**：向证监会提交申请
6. **反馈回复**：多次反馈回复，解决监管关注问题
7. **发行上市**：通过发审会，成功发行上市

**案例启示** 💡

> - **充分的尽职调查**是项目成功的基础
> - **及时、准确的反馈回复**至关重要
> - **团队协作**是关键

### 10.2 案例二：某公司债券发行项目

**项目背景** 🌐

某企业计划发行**公司债券**，筹集资金用于项目建设。

**承做过程** 📝

1. **项目立项**：评估企业信用状况和偿债能力
2. **尽职调查**：重点关注财务状况和现金流
3. **材料制作**：编制募集说明书
4. **信用评级**：聘请评级机构进行信用评级
5. **监管申报**：向交易所提交申请
6. **发行上市**：成功发行并上市交易

**案例启示** 💡

> - **信用评级**对债券发行至关重要
> - **偿债能力**是监管关注重点

## 十一、总结 📋

> **项目承做**是证券发行的核心环节，需要承销商具备专业的知识和丰富的经验。通过严格的**尽职调查**、规范的**材料制作**和高效的**沟通协调**，确保项目顺利推进，最终实现证券成功发行上市。
