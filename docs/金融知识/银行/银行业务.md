# 银行业务

## 一、资产业务

> **资产业务**：银行运用资金的业务，是银行收益的主要来源

### 1.1 贷款业务

#### 1.1.1 贷款分类

**按期限分类**

| 期限 | 定义 | 适用场景 |
|------|------|----------|
| **短期贷款** | 1年以内（含1年） | 企业流动资金周转 |
| **中期贷款** | 1-5年（含5年） | 设备更新、技术改造 |
| **长期贷款** | 5年以上 | 项目建设、房地产开发 |

**按用途分类**

| 类型 | 用途 |
|------|------|
| **流动资金贷款** | 满足企业日常生产经营周转 |
| **固定资产贷款** | 用于固定资产投资项目 |
| **项目贷款** | 用于特定项目建设 |
| **个人消费贷款** | 用于个人消费支出 |
| **个人住房贷款** | 用于购买住房 |
| **个人经营贷款** | 用于个体工商户经营活动 |

**按担保方式分类**

| 类型 | 特点 |
|------|------|
| **信用贷款** | 仅凭借款人信用发放，风险较高 |
| **保证贷款** | 由第三方提供保证担保 |
| **抵押贷款** | 以抵押物为担保（如房产、设备） |
| **质押贷款** | 以质押物为担保（如存单、债券） |

**按风险程度分类（五级分类）**

| 级别 | 含义 | 风险程度 |
|------|------|----------|
| **正常类** | 借款人能按时足额偿还本息 | 低 |
| **关注类** | 借款人偿还能力出现不利因素 | 较低 |
| **次级类** | 借款人明显无法足额偿还本息 | 较高 |
| **可疑类** | 借款人无法足额偿还本息，损失较大 | 高 |
| **损失类** | 借款人已无法偿还，损失已确定 | 极高 |

#### 1.1.2 贷款流程

```
客户申请 → 贷前调查 → 风险评估 → 贷款审批 → 签订合同 → 贷款发放 → 贷后管理 → 贷款回收
    ↓           ↓          ↓          ↓          ↓          ↓          ↓          ↓
 提交资料   资质审查   信用评级   权限审批   法律文件   资金划转   跟踪监测   本息收回
```

> **关键环节**：贷前调查和贷后管理是控制风险的核心

#### 1.1.3 贷款利率

| 类型 | 定义 |
|------|------|
| **基准利率** | 由中国人民银行公布的基准利率 |
| **浮动利率** | 在基准利率基础上上下浮动（如上浮10%） |
| **固定利率** | 在贷款期内利率保持不变 |
| **市场利率** | 由市场供求关系决定的利率 |

### 1.2 投资业务

#### 1.2.1 债券投资

| 类型 | 风险 | 收益 |
|------|------|------|
| **政府债券**（国债、地方政府债） | 低 | 低 |
| **金融债券**（政策性银行债、商业银行债） | 较低 | 较低 |
| **企业债券**（公司债、企业债） | 较高 | 较高 |

#### 1.2.2 同业投资

- 同业拆借
- 同业存单
- 同业借款

#### 1.2.3 其他投资

- 基金投资
- 股权投资
- 衍生品投资

---

### 1.3 票据业务

| 业务类型 | 定义 | 参与方 |
|----------|------|--------|
| **票据承兑** | 银行承诺在票据到期日无条件支付款项 | 银行、出票人 |
| **票据贴现** | 持票人将未到期票据转让给银行 | 持票人、银行 |
| **票据转贴现** | 银行将已贴现票据转让给其他金融机构 | 银行、其他金融机构 |
| **票据再贴现** | 银行将已贴现票据转让给中央银行 | 银行、央行 |

## 二、负债业务

> **负债业务**：银行吸收资金的业务，是银行资金的主要来源

### 2.1 存款业务

#### 2.1.1 存款分类

**按存款主体分类**

| 主体 | 特点 |
|------|------|
| **单位存款** | 企业、机关事业单位等存款，金额较大 |
| **个人存款** | 居民个人存款，数量众多 |

**按存款期限分类**

| 类型 | 特点 |
|------|------|
| **活期存款** | 随时存取，无固定期限，利率较低 |
| **定期存款** | 固定存期，利率较高，提前支取按活期计息 |
| **定活两便存款** | 存期灵活，利率按实际存期计算 |

**定期存款种类**

| 类型 | 特点 |
|------|------|
| **整存整取** | 一次性存入，到期一次性支取 |
| **零存整取** | 分次存入，到期一次性支取 |
| **整存零取** | 一次性存入，分次支取 |
| **存本取息** | 一次性存入，分次支取利息 |

#### 2.1.2 存款特点

- ✅ **安全性高**：受存款保险制度保护
- ✅ **流动性强**：活期存款可随时支取
- ✅ **收益稳定**：定期存款利率固定

#### 2.1.3 存款保险制度

> **保障范围**：人民币和外币存款

| 项目 | 内容 |
|------|------|
| **最高偿付限额** | 50万元人民币 |
| **保费缴纳** | 由银行缴纳 |
| **覆盖范围** | 存款类金融机构吸收的人民币和外币存款 |

---

### 2.2 借款业务

| 类型 | 定义 |
|------|------|
| **同业借款** | 银行之间的短期资金融通 |
| **再贷款** | 中央银行对商业银行的贷款 |
| **再贴现** | 商业银行将票据贴现给中央银行 |
| **金融债券** | 银行通过发行债券筹集资金 |
| **同业存单** | 银行在银行间市场发行的短期融资工具 |

---

### 2.3 其他负债业务

- **结算性负债**：在结算过程中形成的临时性负债
- **或有负债**：可能转化为实际负债的项目（如保函、信用证）

---

## 三、中间业务

> **中间业务**：银行不运用自有资金，为客户提供服务并收取手续费的业务

### 3.1 结算业务

#### 3.1.1 支付结算

| 工具 | 特点 |
|------|------|
| **支票** | 出票人签发，委托银行付款 |
| **汇票** | 出票人签发，委托付款人付款 |
| **本票** | 出票人签发，承诺自己付款 |
| **银行卡** | 集存款、取款、消费、结算于一体 |

#### 3.1.2 国际结算

| 方式 | 特点 |
|------|------|
| **信用证** | 银行信用担保，国际贸易常用 |
| **托收** | 委托银行代收款项 |
| **汇付** | 直接通过银行汇款 |

---

### 3.2 代理业务

| 类型 | 具体内容 |
|------|----------|
| **代理收付款** | 代收水电费、物业费；代发工资、奖金 |
| **代理证券** | 代理发行、兑付、买卖证券 |
| **代理保险** | 代理销售保险产品、收取保费、理赔 |
| **代理财政** | 代理国库、代理财政收支 |

---

### 3.3 咨询业务

- 财务顾问
- 投资咨询
- 风险管理咨询
- 金融政策咨询

---

### 3.4 保管业务

| 类型 | 内容 |
|------|------|
| **保管箱业务** | 为客户提供贵重物品保管服务 |
| **有价证券保管** | 保管股票、债券等有价证券 |
| **贵重物品保管** | 保管金银首饰、重要文件等 |

---

### 3.5 银行卡业务

#### 3.5.1 借记卡 vs 信用卡

| 特征 | 借记卡 | 信用卡 |
|------|--------|--------|
| **资金来源** | 自有存款 | 银行授信 |
| **透支功能** | 无 | 有 |
| **免息期** | 无 | 有 |
| **年费** | 较低或免费 | 较高 |
| **主要用途** | 存取款、消费结算 | 消费、资金融通 |

#### 3.5.2 信用卡分类

| 卡种 | 额度 | 适合人群 |
|------|------|----------|
| **普卡** | 较低 | 信用小白 |
| **金卡** | 适中 | 普通白领 |
| **白金卡** | 较高 | 中高收入人群 |
| **钻石卡** | 高 | 高端客户 |

#### 3.5.3 信用卡业务流程

```
客户申请 → 资质审核 → 卡片发放 → 激活使用 → 消费还款 → 风险管理
```

---

### 3.6 电子银行业务

| 渠道 | 特点 |
|------|------|
| **网上银行** | 电脑端操作，功能全面 |
| **手机银行** | 移动端操作，便捷灵活 |
| **电话银行** | 语音服务，全天候 |

## 四、表外业务

> **表外业务**：不反映在资产负债表中，但可能转化为表内业务的业务

### 4.1 担保类业务

| 类型 | 内容 |
|------|------|
| **保函** | 投标保函、履约保函、预付款保函等 |
| **备用信用证** | 作为备用担保的信用证 |
| **承兑汇票** | 银行承兑的商业汇票 |

### 4.2 承诺类业务

| 类型 | 内容 |
|------|------|
| **贷款承诺** | 承诺在未来一定期限内提供贷款 |
| **信贷额度** | 为客户核定的信用额度 |
| **票据发行便利** | 承诺为客户发行票据提供便利 |

### 4.3 金融衍生品类业务

| 类型 | 特点 |
|------|------|
| **远期合约** | 约定未来交易的合约 |
| **期货** | 标准化的远期合约 |
| **期权** | 有权利但无义务的合约 |
| **互换** | 交换现金流的合约 |

### 4.4 资产证券化业务

| 类型 | 基础资产 |
|------|----------|
| **住房抵押贷款证券化** | 住房抵押贷款 |
| **资产支持证券** | 各类资产（如应收账款） |
| **担保债务凭证** | 多种资产组合 |

## 六、业务风险管理

### 6.1 风险分类与防控

| 风险类型 | 主要表现 | 防控措施 |
|----------|----------|----------|
| **信用风险** | 贷款违约、交易对手违约 | 信用评估、担保要求、贷后管理 |
| **市场风险** | 利率波动、汇率波动、股价波动 | 风险对冲、限额管理 |
| **操作风险** | 内部欺诈、外部欺诈、系统故障 | 内部控制、审计监督 |
| **流动性风险** | 资金短缺、挤兑 | 流动性储备、融资渠道 |

### 6.2 风险管理框架

```
风险识别 → 风险评估 → 风险控制 → 风险监测 → 风险报告
```

---

## 七、总结

银行业务涵盖**资产、负债、中间业务**等多个领域，随着金融创新和技术进步，业务种类不断丰富。银行通过**风险管理**确保业务稳健运营，为实体经济提供全方位的金融服务。
