# 银行基础

## 一、银行的定义与起源

### 1.1 定义

银行是**依法设立**的经营货币信贷业务的金融机构，是商品货币经济发展到一定阶段的产物。

> **核心职能**：信用中介、支付中介、信用创造、金融服务

### 1.2 起源

| 时期 | 地点 | 关键发展 |
|------|------|----------|
| 11-12世纪 | 意大利威尼斯 | 货币兑换商发展出存款、贷款、汇兑业务 |
| 唐代 | 中国 | 出现"柜坊"，从事货币存放和汇兑 |
| 1694年 | 英国伦敦 | 成立**英格兰银行**，现代银行诞生标志 |

### 1.3 银行的本质特征

- **以盈利为目的**的企业
- 经营特殊商品——**货币和货币资本**
- 经营方式主要是**借贷**
- 具有**创造信用**的功能

## 二、银行的分类

### 2.1 按所有权性质分类

| 类型 | 特点 | 代表银行 |
|------|------|----------|
| **国有银行** | 国家出资设立或控股 | 工商银行、建设银行、中国银行、农业银行、交通银行 |
| **股份制商业银行** | 企业法人和自然人共同出资 | 招商银行、中信银行、浦发银行、兴业银行 |
| **城市商业银行** | 城市信用社改制而来，服务地方经济 | 北京银行、上海银行、南京银行 |
| **农村商业银行** | 农村信用社改制而来，服务农村经济 | 各地农村商业银行 |
| **外资银行** | 外国资本设立或参股 | 汇丰银行、花旗银行、渣打银行 |

### 2.2 按业务范围分类

#### 中央银行
> 国家最高金融管理机构
- **职能**：发行货币、制定货币政策、监管金融机构
- **中国央行**：**中国人民银行**

#### 商业银行
> 银行体系的主体
- **职能**：存贷款、结算、汇兑等

#### 政策性银行
> 政府设立，执行国家产业政策，**不以盈利为主要目的**
- **国家开发银行**：支持国家重点项目建设
- **中国进出口银行**：支持进出口贸易
- **中国农业发展银行**：支持农业发展

### 2.3 按地域范围分类

- 📍 **全国性银行**：业务覆盖全国
- 🌍 **区域性银行**：服务特定区域
- 🏠 **地方性银行**：服务本地社区

## 三、银行的职能

### 3.1 信用中介职能

**最基本的职能**：银行通过吸收存款、发放贷款，实现资金从盈余单位向赤字单位的转移。

```
存款人 → 银行 → 借款人
  (资金盈余)       (资金短缺)
```

### 3.2 支付中介职能

银行通过办理转账结算、现金收付等业务，充当社会经济活动的支付中介。

> **重要作用**：减少现金使用，提高资金流转效率

### 3.3 信用创造职能

**商业银行特有职能**：银行通过贷款派生创造存款货币，扩大货币供应量。

### 3.4 金融服务职能

提供多样化的金融服务：

| 服务类型 | 具体内容 |
|----------|----------|
| 咨询服务 | 财务顾问、投资咨询 |
| 代理业务 | 代收代付、代理保险 |
| 保管业务 | 保管箱、有价证券保管 |
| 投资理财 | 基金、理财产品销售 |

### 3.5 调节经济职能

通过**信贷政策**、**利率政策**等手段，调节社会经济活动。

## 四、银行的组织架构

```
总行 (最高管理机构)
  ├── 分行 (区域管理)
  │     └── 支行 (基层营业)
  └── 职能部门
        ├── 风险管理部
        ├── 信贷管理部
        ├── 财务管理部
        ├── 人力资源部
        ├── 信息技术部
        └── 法律合规部
```

### 4.1 总行

- 制定战略规划
- 制定业务政策和管理制度

### 4.2 分行

- 按行政区划或经济区域设立
- 负责区域内业务管理和拓展

### 4.3 支行

- 银行的基层营业机构
- 直接面向客户提供服务

### 4.4 职能部门

| 部门 | 职责 |
|------|------|
| **风险管理部** | 识别、评估、控制风险 |
| **信贷管理部** | 贷款审批、贷后管理 |
| **财务管理部** | 财务核算、预算管理 |
| **人力资源部** | 人员招聘、培训、绩效考核 |
| **信息技术部** | 系统开发、维护、安全 |
| **法律合规部** | 合规审查、法律事务 |

## 五、银行的主要业务流程

### 5.1 存款业务流程

1. **客户开户申请** → 2. **身份验证** → 3. **账户开立** → 4. **资金存入** → 5. **利息计算与支付**

### 5.2 贷款业务流程

```
客户申请 → 贷前调查 → 风险评估 → 贷款审批 → 签订合同 → 贷款发放 → 贷后管理 → 贷款回收
    ↓           ↓          ↓          ↓          ↓          ↓          ↓          ↓
 提交资料   资质审查   信用评级   权限审批   法律文件   资金划转   跟踪监测   本息收回
```

### 5.3 结算业务流程

1. **客户提交结算凭证** → 2. **银行审核凭证** → 3. **资金划转** → 4. **账务处理** → 5. **回单反馈**

## 六、银行与其他金融机构的区别

### 6.1 银行 vs 证券公司

| 特征 | 银行 | 证券公司 |
|------|------|----------|
| **主营业务** | 存贷款、结算 | 证券发行、交易 |
| **资金来源** | 存款 | 自有资金、客户保证金 |
| **监管机构** | 银保监会 | 证监会 |
| **风险特征** | 信用风险为主 | 市场风险为主 |
| **融资方式** | 间接融资 | 直接融资 |

### 6.2 银行 vs 保险公司

| 特征 | 银行 | 保险公司 |
|------|------|----------|
| **主营业务** | 存贷款 | 保险承保、理赔 |
| **资金运用** | 贷款、投资 | 投资为主 |
| **经营周期** | 短期为主 | 长期为主 |
| **监管机构** | 银保监会 | 银保监会 |

### 6.3 银行 vs 信托公司

| 特征 | 银行 | 信托公司 |
|------|------|----------|
| **业务性质** | 间接融资 | 直接融资 |
| **资金管理** | 被动管理 | 主动管理 |
| **风险承担** | 银行承担 | 委托人承担 |
| **收益来源** | 利差 | 信托报酬 |

## 七、银行的发展趋势

### 7.1 数字化转型

- 📱 **移动银行**：随时随地办理业务
- 💻 **网上银行**：全天候在线服务
- 🤖 **智能客服**：AI驱动的客户服务
- 📊 **大数据风控**：精准风险识别

### 7.2 普惠金融

- 服务**小微企业**
- 服务**乡村振兴**
- 服务**弱势群体**

### 7.3 综合化经营

> **一站式金融服务**：银行+证券+保险

### 7.4 国际化发展

- 🌐 **跨境业务**
- 🏦 **海外分支机构**
- 💱 **人民币国际化**

## 八、总结

银行作为现代金融体系的**核心**，承担着资金融通、支付结算、信用创造等重要职能。随着经济发展和技术进步，银行不断创新业务模式，拓展服务领域，在国民经济中发挥着**不可替代**的作用。
